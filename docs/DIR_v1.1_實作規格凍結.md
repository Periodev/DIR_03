> 目的：供 Claude Code 端實作原型。本文檔為規則層唯一權威來源；
> 與舊筆記（含 6/17 滑行語意）衝突處，以本文檔為準。

## 0. 核心語意一句話

方向（向量）是玩家意圖的一次性錄音：推動鑄造它，安裝預埋它，觸發重播它——
重播的力度上限恰為玩家本人的一次推動（一實體、一格）。

---

## 1. 行為規則（規則層，共 13 條）

### R1 推動是初級操作
- 玩家按下方向鍵、該方向的相鄰格為方塊、且玩家原本未朝向該方塊時，本次操作只更新朝向；不移動、不推動、不改變玩家隊列。
- 玩家已正對相鄰方塊時，再按同方向才判定推動是否成立。
- 玩家面向格有方塊、且方塊後方格可進入時，推動成立。
- 方塊前進一格；**玩家保持原位，不隨行**。
- 玩家隊列狀態不能禁止推動。

### R2 推動可產生方向
- 推動成功時，產生該次推動方向（上/下/左/右）。
- 新方向依 R3 寫入玩家隊列。

### R3 玩家隊列容量為 1，新方向覆蓋舊方向
- 推動成功 → 新方向寫入玩家隊列。
- 玩家隊列已有方向時，新方向覆蓋舊方向。
- 玩家隊列恆等於最後一次成功推動的方向。

### R4 方向可安裝到方塊（X）
- 條件：玩家隊列非空、面向格有方塊、該方塊未持有方向。
- 成功：隊列方向寫入方塊，玩家隊列清空，方塊進入安裝序列尾端。
- 無手持態：出列即安裝，中間不存在暫存狀態。

### R5 已占用方塊拒絕新安裝
- 方塊已持有方向時，X 操作無效：不覆蓋、不交換、不觸發原方向。
- （覆寫行為封存，待謎題需求出現再議。）

### R6 觸發依安裝順序（Space）
- 每次觸發只處理安裝序列隊首（最早安裝且未消耗者）。
- 後安裝者不可越序。

### R7 觸發＝重播一次玩家推動
- 單次成功觸發，恰好一個實體位移恰好一格（能力守恆）。

### R8 觸發前方為空：載體自身移動
- 隊首方塊沿已安裝方向步進一格。

### R9 觸發前方有單一方塊：定—動模型
- 持有方向的方塊**不動**；前方方塊沿該方向被推一格。
- 不產生新方向、不轉移任何狀態（被推方塊若持有方向，原封不動隨行）。

### R10 不允許連鎖／整列推動
- 前方方塊的後方仍被占用（第二塊、牆、玩家）→ 不發生任何實體位移，但仍依 R11 消耗本次方向。

### R11 每次有效觸發嘗試都消耗
- 安裝序列非空時按下 Space，必定處理並消耗隊首方塊的方向，將其移出安裝序列。
- 可位移 → 依 R8 或 R9 完成一次位移後消耗。
- 被牆、邊界、柵欄、玩家或不可推動的方塊阻擋 → 無實體位移，方向仍消失並移出安裝序列。
- 安裝序列為空時按 Space 是無效操作，不消耗任何狀態。
- 一觸發＝一步＝一向量；遠端位移 N 格需 N 次採集→安裝→觸發循環。

### R12 方向隨方塊（狀態不可越權）
- 已安裝方向只被該方塊輪到隊首時的觸發嘗試消耗。
- 被玩家推動或被其他方塊推動時，方向不觸發、不轉移、不消耗，仍隨原方塊移動。
- 阻擋消耗只作用於目前隊首方塊，不影響其他已安裝方塊及其順序。

### R13 玩家是純障礙（v1）
- 觸發路徑上為玩家 → 玩家與方塊皆不移動；隊首方向消耗。
- 塊推玩家（rebound 系）未定義，列為擴充討論項，非否決項。

### 不變量（貫穿檢查用）
- **入列/出列分離**：推動只寫玩家隊列，觸發只讀方塊方向，兩層互不越權。
- **單載體單方向**：玩家隊列與方塊槽皆容量 1。
- **向量經濟封閉**：只有玩家親手推動能鑄造方向；碰撞不產出。
- **能力守恆**：任何單次位移事件 ≤ 一實體一格。

### 勝利條件
- 關卡至少有一個目標格時，所有目標格皆被任一方塊占據即通關。
- 判定只看方塊；玩家站在目標格上不算完成。
- 允許額外工具塊留在目標格外。
- 通關後停止一般操作，只保留 F5 重置。

## 2. 實作規格（Godot / GDScript）

### 資料
| 舊 | 新 |
|---|---|
| `momentum_slot: String` | `player_queue: String`（空字串＝空；初版容量 1） |
| `block_cells: Array[Vector2i]` | `blocks: Array[Dictionary]`，每塊 `{id, cell, vector}` |
| — | `install_order: Array[int]`（存方塊 **id**，不存陣列索引） |

- `id` 固定且唯一（日後方塊消滅/增生時索引會漂移，id 不會）。

### 輸入
- 新增 `install_vector`（X）、`trigger_vector`（Space）。
- **輸入原子性**：一次操作完成前不處理下一次輸入，防連按 Space 重複處理隊首。

### 操作流程
1. **轉向**：方向鍵指向相鄰方塊、且玩家原本未朝向該方塊 → 只更新朝向；不移動、不推動、不動隊列。
2. **移動**：方向鍵指向空格 → 玩家移動並朝向該方向；不產生方向、不動隊列。
3. **推動**：玩家已正對相鄰方塊，且再次按下同方向、塊後方可入 → 塊進一格、**玩家原位**；
   新方向無條件寫入 `player_queue`，覆蓋舊方向；推動照常完成。
4. **X**：R4 條件全滿足才生效；成功寫入塊、清隊列、id 入 `install_order` 尾；失敗零狀態變更。
5. **Space**：取 `install_order` 隊首 id；
   - 前方空 → 塊移一格、清 vector、移除隊首。
   - 前方單塊且其後方可入 → 載體不動、前塊移一格、清載體 vector、移除隊首。
   - 前方為牆/邊界/柵欄/玩家，或前塊後方受阻，或連續兩塊以上 → 無實體位移；清載體 vector、移除隊首。
   - `install_order` 為空 → 無效操作，狀態不變。

### HUD（最小集）
- 玩家隊列當前方向。
- 持有方向的方塊上顯示箭頭。
- 除錯模式：顯示安裝序列。

### v1 明確排除
pop-push／主動丟棄方向／覆寫方塊方向／多塊連推／自動連鎖觸發／
碰撞方向轉移／推動自動觸發／隊列容量 >1／滑行（一切位移皆步進）／
塊推玩家（rebound 系，擴充討論項）。

## 3. 驗收關卡（三關，各壓一組規則）

圖例：`#`牆　`@`玩家　`A` `B`方塊　`*`目標　`.`空地
勝利條件：**B 停在 `*` 上**。玩家可暫佔目標格（判定只看方塊）。

### 關一：井題 — 遠端觸發必要性（壓 R6/R8/R11/R13）

```
#####
##B##
##*##
##.A#
###.#
#####
```

解序：推 A 下一格（「下」入列）→ 站 B 正下方（唯一鄰接開格＝目標格）X 安裝
→ 側移讓開井口 → Space，B 單步落目標。

證明：B 三面封牆，唯一鄰接格即目標格；鄰接觸發版站上去即堵死 B 的一步
（R13 玩家為障礙 → 方塊不移動且方向耗散）——嚴格無解。遠端觸發為必要。∎

### 關二：L 型題 — 90° 錯位＋覆蓋入列確認（壓 R3/R9 路徑/R12）

```
#####
#@.##
#A.##
#.B.#
#.#*#
#####
```

解序：推 A 下（「下」入列）→ **再推 A 下讓位（同值覆蓋，無害）**
→ 站 B 上方 X 安裝「下」→ 站 B 左側推右一格
（「右」入列但不用；B 身上的「下」隨行＝R12 實證）→ Space，B 步進入死角目標。

無捷徑：直推路線的下推位是牆；B 直接下推被牆擋死；左推為死分支。
唯一通路是推入方向 ⊥ 發射方向。

### 關三：錨定題 — 定—動語意展示（壓 R7/R9）

構型要件（成關時依此布置）：
- A 持「下」，A 正下方一格為 B，B 再下方一格為 `*`。
- A 當前壓著的格子是玩家後續必經的唯一橋點（左右皆牆的走廊口）。

解序：Space——A 不動、B 被撥一格入目標；A 繼續守橋，玩家過橋。
展示：守位與出力解耦（錨定推），「觸發＝遠處重播一次玩家推動」的最佳教學題。
（齊動模型下 A 被迫離位堵走廊，此題無解——本關即兩模型的判別題。)
